2. Theme and the list of features

This project is a Text / Log File Viewer, developed using Rust and the Iced GUI.

The application allows users to open text or log files, search for specific keywords, count matching lines, and save search history in a MySQL database.

Features:

-Open and display text or log files.
-Filter lines using a keyword.
-Count matching lines.
-Save and view search history using MySQL.
-Navigate between Search, History, and Tutorial screens.
-Switch between light and dark themes.
-Export search results to a TXT file.
-Confirm or cancel before exporting.
-Display error messages for invalid file paths.
-Display a loading state while opening files.
